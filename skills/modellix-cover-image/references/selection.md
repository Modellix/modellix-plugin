# Choosing the dimensions

Recommend one full set. Give each pick a one-line reason taken from the source. The content picks the metaphor. These tables only pick the style.

If two rows match, choose the one that matches the article's job, and say so. Do not silently average two palettes.

## Type

| Signals in the source | Type |
| --- | --- |
| Launch, release, announcement, a product reveal | hero |
| Architecture, system, API, method, model | conceptual |
| A quotation, an opinion, a line that is the whole point | typography |
| Growth, meaning, reflection, an idea with no literal object | metaphor |
| A journey, a place, a lived story | scene |
| One essential idea the author wants left quiet | minimal |

## Text, mood, and font

Text defaults to title-only.

| Signals | Text level |
| --- | --- |
| The user asked for no words, or the picture is the whole statement | none |
| A normal article or blog cover | title-only |
| A series or a tutorial that needs one line of context | title-subtitle |
| An announcement with two short labels beyond the title | text-rich |

A text-rich cover that starts listing steps, comparisons, or metrics is an infographic. Hand it to `modellix-infographic`.

| Signals | Mood |
| --- | --- |
| Academic, corporate, luxury | subtle |
| A normal essay or lesson | balanced |
| A launch, a promotion, entertainment | bold |

Mood defaults to balanced.

| Signals | Font character |
| --- | --- |
| Technical, modern, quiet | clean |
| Personal, warm, a story | handwritten |
| Editorial, literary, classic | serif |
| An event, a game, a shout | display |

Font character defaults to clean. Describe it in the prompt as letterform character. Do not name a commercial typeface.

## Aspect and language

Aspect defaults to 16:9. Offer 2.35:1 for a cinematic banner, 1:1 for a square, and 3:4 for a portrait cover. On-image language follows the source title. A Chinese article keeps a Chinese title inside an English prompt.
