# Renderings

The rendering is how marks are made. State it in the prompt as line, fill, and texture. Do not name a software tool.

| Rendering | Marks |
| --- | --- |
| flat-vector | Even fills, geometric edges, no gradients, no texture. |
| hand-drawn | Uneven ink lines, small wobble, paper showing through. |
| painterly | Soft edges, visible strokes, color mixed at the boundaries. |
| digital | Smooth shapes, a little depth, polished highlights, still not a photograph. |
| pixel | Chunks on a grid, limited colors, hard stair steps. |
| chalk | Dusty strokes on a dark board, soft halos, no glossy highlights. |
| screen-print | Flat ink, one or two layers, hard silhouettes, a slight misregistration. |

A photographic product or a realistic poster is not one of these renderings. That request belongs to `modellix-image-prompt-engineering`.

Icons follow the rendering. A flat-vector gear is a simple shape. A chalk gear is a dusty stroke. Do not paste a clip-art set into a painterly scene.
