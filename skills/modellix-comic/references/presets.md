# Preset rules

A preset adds rules on top of its base art, tone, and layout. Apply every rule below when that preset is confirmed. If the user changes one base dimension, keep the rules.

Characters are original. Describe a role, not a copyrighted mascot. Do not name or imitate a famous cartoon character.

## ohmsha

For a tutorial or a technical explanation.

- Give the learner a distinct silhouette and the guide a different one. An optional third figure can embody the misconception.
- Do not draw a panel that is only people talking. Each idea becomes a prop the characters hold, an action they perform, or a place they walk into.
- A formula, a model, or a system is a visible object: a machine, a path, a set of weights, a door. The object does the explaining.
- Page roles are scene sentences, such as "the learner drops a ball into a valley," not "Introduction to gradient descent."
- End on a small demonstration that the opening problem is now solved. Do not end on "what do you think?" or a thank-you panel.
- Prefer `webtoon`. Use `dense` only for a procedure the user asked to keep step by step. Avoid `splash` and `cinematic` for this preset.

## concept-story

For an abstract idea told through one character's change.

- Invent one symbol, such as a knot, a key, or a growing plant. The symbol changes state as the character understands the idea.
- Balance a line of dialogue with an action in the same page. Do not let either carry the page alone.
- The ending shows the character using the idea, with the symbol in its final state.

## four-panel

For one short insight.

- One page, exactly four panels: setup, development, turn, payoff.
- Black ink plus one spot color. Simplified figures. No character sheet.
- The turn panel changes the meaning of the setup. The payoff is a visual result, not a slogan the source did not contain.
- Skip this preset when the source needs a sequence longer than four beats. Recommend `ohmsha` or `concept-story` instead.

## wuxia

Use when the user asked for a martial-arts comic.

- Ink and empty paper carry the space. Qi, force, and impact are visible strokes, dust, and light, not a labeled diagram.
- The decisive exchange is a `splash`. Earlier pages can be `cinematic` if the user wants the approach.
- Weapons, stance, and costume stay consistent in the cast lock.

## shoujo

Use when the user asked for a romantic or school-life comic.

- Decorative frames and expressive eyes stay inside the panel borders. They do not cover quoted text.
- Emotional beats are shown in gesture and setting. A confession, a pause, and a small object can carry a page.
- Keep the same costume colors across pages so the sheet, when there is one, still matches.
