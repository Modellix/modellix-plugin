# What the names look like

Describe the confirmed names in ordinary visual language inside the prompt. Do not paste this file into the prompt.

## Art

| Name | Look |
| --- | --- |
| `ligne-claire` | Even ink outlines, flat local color, little shading, clear backgrounds, readable small objects |
| `manga` | Expressive faces, speed lines, high-contrast black shapes, full color rather than screentone dots |
| `realistic` | Observed proportions, period clothing and tools, restrained expressions, drawn rather than photographed |
| `ink-brush` | Visible brush strokes, ink wash, large areas of untouched paper, motion carried by the stroke |
| `chalk` | Dusty strokes on a dark board, limited colors, simple icons drawn as if by hand with chalk |
| `minimalist` | Few lines, simplified figures, one spot color, large areas of empty ground |

## Tone

| Name | Look |
| --- | --- |
| `neutral` | Even light, clear color, an explanatory calm |
| `warm` | Amber light, soft shadows, approachable faces |
| `dramatic` | Deep shadow, one strong light, a held pause |
| `romantic` | Soft glow, decorative frames, gentle sparkle kept off the lettering |
| `energetic` | Saturated color, tilted panels, motion that continues into the gutter |
| `vintage` | Muted inks, paper age, period props without fake stains covering the drawing |
| `action` | Impact frames, dust, speed, a readable silhouette at the hit |

## Layout

| Name | Look |
| --- | --- |
| `standard` | Four to six panels, even gutters, a clear top-to-bottom or left-to-right path |
| `cinematic` | Two or three wide panels, more environment than close-up |
| `dense` | Many small panels for a procedure or a sequence of small beats |
| `splash` | One panel dominates the page for a breakthrough or a blow |
| `mixed` | Panel size changes with the beat; the page still has one reading path |
| `webtoon` | Panels stacked for a vertical scroll, with space between beats |
| `four-panel` | Exactly four panels in one page: setup, development, turn, payoff |

Gutters stay empty. Do not put narration in the gutter.

## Reading order

State the order in the prompt.

- `webtoon`: top to bottom.
- `manga` on a paged layout, when the on-image language is Chinese or Japanese: right to left, top row before the next row.
- Every other paged layout: left to right, top row before the next row.
- `four-panel`: the order of setup, development, turn, payoff. Say whether the four panels are stacked or in a square.
