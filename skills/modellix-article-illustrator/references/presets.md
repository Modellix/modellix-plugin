# Presets

A preset expands to a type, a style, and an optional palette. If the user changes one of those, keep the other two and say what changed.

| Preset | Type | Style | Palette | Use |
| --- | --- | --- | --- | --- |
| `hand-drawn-edu` | `infographic` | `sketch-notes` | `macaron` | A general explainer, onboarding, a concept with no stronger signal |
| `hand-drawn-edu-flow` | `flowchart` | `sketch-notes` | `macaron` | A how-to or a workflow in the same hand-drawn notes |
| `tech-explainer` | `infographic` | `blueprint` | style default | An API, a metric, a technical deep dive |
| `system-design` | `framework` | `blueprint` | style default | Architecture, modules, a system of parts |
| `tutorial` | `flowchart` | `vector-illustration` | style default | Flat vector steps for a setup guide |
| `versus` | `comparison` | `vector-illustration` | style default | Two or more options, a review |
| `storytelling` | `scene` | `warm` | style default | A personal essay, a journey, a reflection |
| `history` | `timeline` | `elegant` | style default | History, milestones, an evolution |
| `ink-notes-compare` | `comparison` | `ink-notes` | `mono-ink` | A manifesto, a before/after, a professional note |
| `science-paper` | `infographic` | `scientific` | style default | A paper, a lab result, a scientific explanation |

## Rules that travel with the preset

- `hand-drawn-edu` and `hand-drawn-edu-flow`: cream paper, wobbly black lines, pastel blocks, short labels. Do not switch a panel into a photograph.
- `tech-explainer` and `system-design`: schematic lines and zones. People, if any, are small markers, not portraits.
- `tutorial` and `versus`: flat shapes and one idea per zone. Line the labels up.
- `storytelling`: one place and one action per illustration. Do not turn the essay into a chart.
- `history`: one path. Dates and names come from the article.
- `ink-notes-compare`: black ink, empty paper, one accent. The split is the argument.
- `science-paper`: labeled parts, muted color, no decorative doodles.

`mixed` is not a preset. It means each illustration names its own type while the confirmed style and palette stay fixed.
