# Choosing the film

Recommend one structure, one length, one aspect, and whether a person appears. Give each pick a one-line reason from the job of the spot. A choice the user already named wins.

The product category does not pick the structure. A snack, a tool, a garment, a bottle, or a machine can use any row below. Pick from how the film should behave.

## Structure

| The film needs to | Structure | Person |
| --- | --- | --- |
| Show the object itself, with no one explaining it | `sculpture` | no, unless the user asked for a hand |
| Show someone quietly using it | `ritual` | one person |
| Put it inside a designed place, with a person as atmosphere | `world` | one person, or none if the place is the subject |
| Show a situation that changes because the product is used | `contrast` | one person |
| Follow one person through a longer passage of time, with the product as a recurring prop | `day` | one person |

`day` is for a film the user already asked to run 30 seconds or longer. A 15-second spot stays on one of the other four.

If two rows match, choose the one that matches the job and say so.

## Length and shot count

| Length | Shots | Each shot |
| --- | --- | --- |
| 6-second bumper, only when the user asks for one | 3 | about 2 seconds |
| 15 seconds | 5 | about 3 seconds |
| 30 seconds | 8 | about 3 to 4 seconds |
| 45 to 60 seconds | 10 | about 4 to 6 seconds |

15 seconds is the usual recommendation. Do not raise the count to match a long brief. Shorten the film instead.

Use the 10-shot row only when the user names a length of 45 seconds or more. Otherwise stop at 8 shots.

## Aspect

Aspect defaults to 16:9. Use 9:16 when the user asks for a vertical film or a social placement. Offer 1:1 only when the user asks for a square cut.

## Person and costume

When the structure needs a person and the user described none, recommend one plain description: age range, hair, and clothes that fit the product's use. Do not invent a celebrity, a uniform with a logo, or a costume the user already contradicted.

`sculpture` does not ask for a person.
